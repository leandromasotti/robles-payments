# Configuración de Supabase

## 🚀 Configuración Requerida

Para que la aplicación funcione con Supabase, necesitas configurar las siguientes variables de entorno:

### 1. Crear proyecto en Supabase
1. Ir a https://supabase.com
2. Crear una nueva cuenta si no tienes una
3. Crear un nuevo proyecto
4. Esperar a que se configure la base de datos

### 2. Obtener las credenciales
En el dashboard de tu proyecto de Supabase:

1. **Project URL**: 
   - Ir a Settings > API
   - Copiar "Project URL"

2. **Anon Key**:
   - Ir a Settings > API
   - Copiar "anon public" key

### 3. Configurar variables de entorno

Actualiza el archivo `.env.local` con tus credenciales reales:

```bash
# Configuración de Supabase
NEXT_PUBLIC_SUPABASE_URL=https://tu-proyecto.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=tu_anon_key_aqui
```

### 4. Crear la tabla Ventas

Ejecuta este SQL en el SQL Editor de Supabase:

```sql
create table public."Ventas" (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  nombre_empresa character varying null,
  nombre_cliente character varying null,
  importe numeric null,
  constraint Ventas_pkey primary key (id)
) TABLESPACE pg_default;
```

### 5. Configurar políticas de acceso (RLS)

```sql
-- Habilitar Row Level Security
ALTER TABLE public."Ventas" ENABLE ROW LEVEL SECURITY;

-- Permitir lectura para todos
CREATE POLICY "Allow read access for all users" ON public."Ventas"
FOR SELECT USING (true);

-- Permitir inserción para todos
CREATE POLICY "Allow insert access for all users" ON public."Ventas"
FOR INSERT WITH CHECK (true);
```

### 6. Verificar configuración

1. Reiniciar el servidor de desarrollo:
```bash
npm run dev
```

2. Intentar registrar un pago
3. Verificar en Supabase > Table Editor > Ventas que se haya creado la fila

## 🔍 Estructura de datos

### Tabla Ventas
| Campo | Tipo | Descripción |
|-------|------|-------------|
| id | bigint | ID único (autoincremental) |
| created_at | timestamp | Fecha de creación automática |
| nombre_empresa | varchar | Nombre de la empresa |
| nombre_cliente | varchar | Nombre completo del cliente |
| importe | numeric | Monto del pago |

### Flujo de datos
1. **Empresas**: Se leen desde Google Sheets (hoja 1)
2. **Ventas**: Se escriben y leen desde Supabase
3. **Dashboard**: Combina datos de ambas fuentes

## 🚨 Solución de problemas

### Error: "Invalid API key"
- Verifica que las variables de entorno estén configuradas correctamente
- Asegúrate de que el archivo `.env.local` esté en la raíz del proyecto
- Reinicia el servidor de desarrollo

### Error: "Table 'Ventas' doesn't exist"
- Ejecuta el SQL de creación de tabla en Supabase
- Verifica que el nombre de la tabla sea exactamente "Ventas" (con comillas)

### Error: "Row Level Security"
- Configura las políticas de RLS como se muestra arriba
- O deshabilita RLS temporalmente para pruebas

### Los datos no aparecen
- Verifica en Supabase > Table Editor que los datos se estén guardando
- Revisa la consola del navegador para errores
- Confirma que las credenciales sean correctas
